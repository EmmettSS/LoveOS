# نشانِ LoveOS — بسته‌ی هویت بصری

نشان از **گردنبندِ نقره‌ی هدیه** گرفته شده: قلبِ بازی که خطِ پایین‌راستش، همان‌طور که
پایین می‌آید، دو حلقه‌ی ∞ را **روی بدنه‌ی خودش** می‌سازد (دو محلِ چسبیدنِ نزدیک و یک
تقاطعِ اریب در کمرِ ∞) و بعد تا نوکِ پایینِ قلب ادامه می‌دهد. یعنی ∞ جزئی از همان خط
است، نه شکلی جدا داخلِ قلب؛ و هر لُب یک‌بار خط را قطع می‌کند — همان حسی که گردنبند
می‌دهد: «قلب و بینهایت، یکی».

## فایل‌ها

| فایل | کاربرد |
|---|---|
| `logo-mark.svg` | نشانِ کامل روی تایلِ تیره — آیکنِ اصلی (فاوآیکون، PWA، داک) |
| `logo-glyph.svg` | بدون پس‌زمینه، براق — روی زمینه‌ی تیره |
| `logo-light.svg` | تایلِ روشن — روی سطح‌های روشن و مستندات چاپی |
| `logo-flat.svg` | تک‌رنگِ رز، بدون گرادیان و نگین — حکاکی، برچسب، قالب |
| `logo-final-preview.png` | پیش‌نمایش یک‌نگاه (خانواده‌ی کامل + سایزهای کوچک) |
| `candidates/` | چهار طرحِ اولیه که در مرحله‌ی انتخاب بررسی شد |
| `generate-logo.mjs` | تولیدکننده؛ همه‌ی دارایی‌های زیر را از یک هندسه می‌سازد (به‌علاوه‌ی بلوکِ اسپلشِ `index.html` و نشانه‌های `admin_gate.html`) |

## بازتولید

```bash
node docs/branding/generate-logo.mjs        # فقط SVG
npm i -D @resvg/resvg-js                    # برای PNGها (اختیاری)
node docs/branding/generate-logo.mjs
```

خروجی: `frontend/public/favicon.svg`، `frontend/public/icons/{logo.svg,app-192.png,
app-512.png,maskable-512.png,apple-touch-icon.png}`، همین پوشه،
`frontend/src/shared/loveosMark.ts` (هندسه‌ای که کامپوننت React و اسپلش از آن
استفاده می‌کنند) و نشانِ داخلِ دروازه‌ی پنل بابا
(`backend/templates/admin_gate.html`، بین نشانه‌های `{# LOVEOS-LOGO #}` و
`{# LOVEOS-FAVICON #}`).

اسپلشِ صفحه‌ی اول هم از همان هندسه ساخته می‌شود: `generate-logo.mjs` فقط بلوکِ
`<svg class="ls-mark">` را در `frontend/index.html` جایگزین می‌کند و طولِ
مسیرها (`--len` در `.ls-a` / `.ls-b`) را برای انیمیشنِ کشیده‌شدن به‌روز می‌کند.

> نکته: `Logo-idea.jpg` در ریشه‌ی پروژه، عکسِ مرجعِ گردنبند است. آن عکس هیچ‌جا در
> رابط کاربری استفاده نمی‌شود؛ همه‌جا نسخه‌ی وکتوری همین نشان است.
